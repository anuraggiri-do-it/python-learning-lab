# GenAi

This folder holds Gen AI learning resources, models, prompts, and examples.

## Structure

- `models/`
  - `Chat_models/` — conversational agent examples
  - `EmbeddedModels/` — embedding pipelines and use cases
  - `LLMs/` — large language model utilities and examples
- `prompts/` — reusable prompt templates and prompt engineering notes
- `Basic/` — beginner Gen AI experiments and toy examples
- `structured-op/` — structured output formats for chain responses
